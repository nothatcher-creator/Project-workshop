# RELICFALL — Reference-Art Edition

Run via `python -m http.server 8000` inside this directory, then visit `http://localhost:8000`.

Features currently present: nine procedurally assembled floors and named bosses, twenty-seven floor-specific enemy specs, 30 agent-forged weapons across ten attack mechanics, 200 effect-bearing relics, 30 persistent achievements, chests, shops, actual secret room encounter, death/restart/levelup, mobile joystick and auto-fire toggle, dodge, full menu, weapon forge and share-code showroom.

Your keeper/underwater-lighthouse/gearworks/leviathan reference art is embedded as source-driven backgrounds and visuals. This is a playable prototype, not the finished animation suite. See the full reference art inventory for remaining sprite images/audio.

Browser storage holds progress. Clear site data to reset; no server-side progress or real-time global multiplayer showcase is implemented.
